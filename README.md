# DataSet Explanations (from branch Jason)

## cleaned_data
The ACLU_merged_cleaned.csv contains Boston's cleaned MassDOT (traffic stop) data from 2020 to 2022.

## data
The (2020, 2021, 2022) ACLU files in this folder are used to produce the ACLU_merged_cleaned.csv.

## notebooks
This folder contains the Jupyter notebook (ACLU_merging_cleaning.ipynb) used to produce the cleaned ACLU_merged_cleaned.csv (MassDOT) in cleaned_data and the notebooks to compare MassDOT with Overtime.
