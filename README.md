# DataSet Explanations (from branch Taiyo)

## cleaned_data
All 4 files in this folder are named with _merged_cleaned. Each file contains cleaned overtime data from 2020 to 2022 (2020 to 2021 for Records_merged_cleaned, due to missing 2022 data for "Records Request").

## data
All files in this folder are used to produce those in cleaned_data.

## notebooks
All files in this folder are Jupyter notebooks used to either produce the files in cleaned_data or to compare overtime shifts (Intra_OT_EDA.ipynb).
